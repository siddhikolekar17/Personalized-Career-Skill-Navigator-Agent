# Feature Overview

## Personalized Career Profile

Users can provide their education, skills, interests, experience, and target career role.

## Skill Gap Analysis

The system compares the user's current skills with the skills required for the selected career and identifies important gaps.

## Personalized Learning Roadmap

The application generates a learning roadmap based on the user's identified skill gaps and career goal.

## Learning Recommendations

Relevant learning resources and activities are suggested to help users improve their skills.

## Progress Dashboard

The dashboard presents personalized results and helps users understand their current progress.

## Career-Focused Guidance

The project connects skill analysis, learning recommendations, and career goals in one platform to support personalized career planning.
